## 新增

- 右邊分割畫面可以回上一個、下一個檔案（← →，滑鼠側鍵也可以）。
- 「直接開啟」在目前分頁開啟右邊的檔案；「在新分頁開啟」把它開到新分頁，左邊的文件不受影響。
- 拖曳中間的分隔線可以調整分割畫面的寬度（會記住），按兩下恢復各佔一半。
- 快速教學從 7 步增加到 9 步：新增「連結在右邊開啟」和「匯出」，也補上搜尋檔案內容、閱讀設定、最近開過的檔案、複製段落連結。

## 修正

- 右邊畫面裡不是 Markdown 的連結（圖片、資料夾、網站）改開在新分頁，不會蓋掉左邊的文件。
- 照 GitHub 寫法的章節連結（標題裡的「.」等符號被拿掉，例如 `#設定檔與-localmk`）現在能跳到標題：主畫面、右邊畫面、從別的檔案用 `檔名.md#章節` 開過來都可以。
- `local.mk`、`setup.py` 這類檔名不再被當成網址變成連結（.mk、.py 是國家網域）。只有寫成 `https://`、`www.` 或 Email 的才是連結，和 GitHub 一樣；想要舊的行為，可在自動連結選項加上 `"bareDomains": true`。
- 打開檔案時不再先閃一下原始文字。

### English

**New**

- The linked-file pane has back and forward (← →, or the mouse's side buttons).
- "Open here" opens the pane's file in this tab; "Open in a new tab" opens it in a new one.
- Drag the line between the two halves to resize the pane (remembered); double-click it for half and half.
- The first-run tour has 9 steps, adding the pane and export, plus search inside files, reading settings, recent files and copying a link to a heading.

**Fixed**

- Links in the pane that are not Markdown (pictures, folders, websites) open in a new tab instead of replacing the document.
- `#heading` links written for GitHub (punctuation such as "." dropped) now jump to the heading, in the document, in the pane, and when a file is opened with such a link.
- File names such as `local.mk` or `setup.py` are no longer turned into web links. `"bareDomains": true` in the auto-link options brings the old behaviour back.
- The raw text no longer flashes before the page is rendered.
